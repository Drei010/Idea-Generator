# Product
<!-- impeccable:product-schema 1 -->

## Platform
adaptive

## Stack
User-specified TypeScript Expo application with Expo Router, Three.js, Zustand, and server-side OpenAI Responses API.

## Product Purpose
Pull a casino-style lever to combine a domain, approach, and niche into one concise practical project idea. Each reel has 46 values for 97,336 combinations; its ten visible faces rotate through the larger category pool each spin.

## Capabilities and Constraints
Each spin requests one idea immediately and keeps the drums turning until it is ready. Retry retains it. Web, iOS, Android. No database, account, credits, hosting, or history. OpenAI key stays server-only. The domain, approach, and niche lists live in separate JSON files under src/domain/data/.

## Brand Commitments
The supplied plan pins a classic red-and-gold casino-style three-reel cabinet and a right-side physical-looking lever.

## Accessibility & Inclusion
Keyboard, touch, mouse, and assistive activation; announced generation status; readable labels; responsive layouts.

## Users
Assumption from the brief: makers looking for a practical starting point for a new project.
